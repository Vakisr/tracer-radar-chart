AWS CloudWatch

Cloud-reported metrics, logs, and alarms across AWS services.

Scope
Account / region / service
Typical signals
Instance/service CPU, memory, network, logs
Cost
High-level (service, account), not per task/process

Tracer (host-observed)

Execution-level signals from the host and container runtime.

Scope
Run → task → container → process
Signals
CPU, memory, disk I/O, network, stalls, failures
Attribution
By user, container, task, run
Infra state (Tracer/sweep)
Idle and orphaned resources
CloudWatch stays responsible for AWS service metrics. Tracer adds host-observed context.

Use CloudWatch to track service health. Use Tracer to explain workload behavior and map resource use and cost to execution units.
